## 🚀 Quick Start & Deployment

### 1. Offline Standalone Access (Zero Server)
- Double-click **`portfolio_standalone.html`** directly in Windows File Explorer.
- Built with `HashRouter` and embedded Base64 image assets for 100% offline compatibility with 0 CORS errors.

### 2. Local Host Server
```bash
# Start local host production preview server on http://localhost:3000/
npx vite preview --port 3000 --host
```

### 3. Production Build
```bash
# Compile production bundle
npm run build
node scripts/fix_double_click.cjs
```
